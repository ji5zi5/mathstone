# UI 검토 · 2026-11-09

실제 로컬 앱을 브라우저에서 조작하며 확인했다. QA는 `localhost:4173`에서 진행했으며, 종료 후 테스트 전 localStorage 전체를 복원했다. 사용자 실행 주소인 `127.0.0.1:4173`의 저장 데이터는 건드리지 않았다.

## 변경

- sprite-gen GPT로 만든 투명 버튼 재질을 홈과 공통 메뉴에 적용. 가변 폭 버튼은 9-slice로 끝부분 비율을 유지한다.
- 홈 하단 네 버튼을 같은 그리드에 정렬. 1280×720에서 중심선은 모두 y=626.
- 대전·상점·모드·투기장 제목을 배경 제목판에 맞춤. 설정·기록·대전방·팩·보상의 제목도 공통 기준으로 정렬.
- 대전의 뒤로 버튼이 제목 위에 겹치던 위치 기준 수정.
- 덱 관리·가져오기·제작·설정·결과 팝업의 텍스트 전용 동작 버튼을 공통 재질로 변경.
- 작은 화면의 서고·상점·대전 준비를 세로 배치로 전환. 카드 상세의 긴 규칙은 스크롤 가능.

## 검증

- 1280×720, 375×812에서 주요 화면을 시각 확인. 768×1024는 홈·서고, 812×375는 홈 확인.
- 최종 홈은 세로·가로 모두 가로 넘침 없음. 375×812의 홈 버튼 최소 높이 44px.
- 812×375의 하단 버튼 높이 56px, 재개 버튼 200×44px. 배경과 버튼의 세로 늘어짐 수정 후 재촬영.
- 모션 감소 설정에서 홈 버튼 transition duration `0s` 확인.
- 브라우저에서 수집된 오류 로그 없음. `node --check src/app.js`, `git diff --check` 통과.
- 전체 자동 테스트 338개 중 337개 통과. 나머지 HTTP 테스트는 샌드박스의 포트 바인딩 EACCES로 실패하여 해당 테스트 파일을 권한 허용 환경에서 재실행했고 6/6 통과.

실물 휴대폰의 터치·OS 글자 확대, 모든 카드 조합, 이번 변경 이후의 두 클라이언트 간 전체 온라인 경기와 관전은 재검증하지 않았다. 전투의 세로 화면은 기존 가로 전장 비율을 유지한다. 모든 상태를 원작과 동일하게 재현했다는 의미는 아니다.
