## 이용 방법

- Word에서는 분야별 목차 링크와 탐색 창으로 이동한다. Markdown은 검색과 내용 보충에 적합하다.
- C로 시작하는 번호는 일반 개념, N으로 시작하는 번호는 정리·대상·이야기다. 소재를 논의할 때 이 번호를 함께 사용하면 항목을 빠르게 찾을 수 있다.
- 설명과 예시로 뜻을 파악하고, 수학 메모에서 성립 조건을 확인한다. 증명이나 역사적 세부사항이 필요하면 각 항목의 출처를 연다.
- 창작 확장은 실제 역사와 구분되는 게임용 이미지다. 전설적인 힘이나 극적인 사건으로 부풀려 활용해도 된다.
- 난도는 설명을 읽기 위한 안내다. 게임 내 희귀도나 강도를 의미하지 않는다.

## 범위

학교 수학의 기본 연산부터 대학 수학의 주요 개념과 명명된 소재까지 폭넓게 수록했다. 수학 전체를 완결한 백과사전은 아니며 이후 소재를 추가할 수 있다. 역사적 전승과 미해결 가설은 해당 항목에 구분해 적었다. 게임 규칙과 밸런스는 이 자료의 범위에 포함하지 않는다.
