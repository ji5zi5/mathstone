# 카드 배치·수식·일러스트 수정

2026-11-09

## 원작과 차이가 컸던 이유

원본에서 추출한 카드 프레임과 폰트를 사용했지만 메뉴 배경은 별도로 생성했고, 카드 유형별 텍스트 영역과 메뉴의 비율을 같은 기준으로 맞추지 못했다. CSS를 덧붙이면서 이전 위치 지정도 남아 있었다. 원본 화면과 동등한 재현을 완료한 상태가 아니다.

참고한 자료: `art-work/references/hearthstone-collection.jpg`, `hearthstone-decks.jpg`, 원본 카드 프레임, `analysis/hearthstone_37.0.255790/presentation/detail/ida/UI_UberText_ResizeTextToFit_266884.annotated.c`.

## 변경

- 글자 수로 폰트를 추정하던 코드를 실제 렌더링된 너비·높이에 맞추는 공통 함수로 교체했다. 주문·무기·하수인의 설명 영역을 각 프레임에 맞췄다.
- 카드 이름의 음수 여백과 겹치는 스타일을 제거했다. 메뉴 버튼·탭·덱 행의 정렬과 서고 쪽번호 위치를 조정했다.
- 복잡한 카드 7종의 표시 문구를 짧게 나누고 함수 카드의 식·변수·턴 효과를 별도 줄에 놓았다. 원본 규칙 문자열은 접근성 레이블과 검색에 유지한다.
- 카드 확대와 전투 미리보기에 MathML 계산식과 변수 뜻을 표시한다. 함수 카드는 현재 식과 x를 표시한다. 긴 스털링 식은 두 줄로 조판한다. 전투 계산은 바꾸지 않았다.
- sprite-gen 4.0.0의 GPT 경로로 확장 카드 20종·연산 카드 4종의 전용 그림을 생성했다. 수집 카드 214종이 서로 다른 그림 셀을 사용한다. 저장된 대전도 카드 ID의 최신 그림을 표시한다.
- 퀘스트 3종·업적 5종에 별도 삽화 8개를 연결했다. 생성 프롬프트와 보고서는 `art-work/unique-22*`, `unique-23*`, `unique-24*`, `journal-icons*`에 있다. 에셋 위치는 `public/art/manifest.json`에 기록했다.

## 확인

- 수학 표시·기존 수학·살아 있는 수식 테스트 33개 통과. 음수·분수·다항식·현재 x·저장값 HTML 이스케이프와 수집 카드 그림 중복을 검증했다.
- 브라우저 1280×720에서 서고 27쪽, 214종 이름·설명 영역의 넘침 0건.
- 베이즈 분수 및 히파티아 제곱근 상세 화면을 육안 확인했다. 확대 창 가로 넘침 0px.
- 390×844에서 스털링 상세 수식과 창 가로 넘침 0px. 세로로 긴 상세 정보는 스크롤한다.
- 새 카드 그림과 퀘스트·업적 삽화의 연결을 브라우저에서 확인했다. 콘솔 오류 0건.

## 남은 차이

메뉴 배경의 원근감과 재질, 버튼의 입체 표현, 화면 전환 및 전투 연출은 원본과 다르다. 실기기 모바일 검증과 원본 클라이언트 전체 장면의 일대일 비교는 수행하지 않았다. 소환물과 영웅을 다른 화면에서 같은 대상으로 표시하는 그림은 유지했다.
