# 메뉴 UI 원작 참고 기록

2026-11-09. 이번 변경 범위는 메인 메뉴, 모드 선택, 상점, 퀘스트·업적·보상의 길이다. 전투 화면과 투기장 내부 화면을 원작과 동일하게 완성했다는 의미는 아니다.

## 참고 화면

- [블리자드 진행·보상 개편 소개](https://hearthstone.blizzard.com/en-gb/news/23534414/non-printable): 공식 퀘스트 화면의 왼쪽 탭, 두루마리 카드, 상단 보상과 하단 진행 표시를 참고했다. 해당 공식 이미지도 브라우저에서 확인했다. 2020년 자료이므로 최신 클라이언트 전체와 일치하는 기준은 아니다.
- [모드 선택 화면 자료](https://hearthstone.wiki.gg/wiki/Modes): 검색 결과에 노출된 실제 화면의 원형 모드 버튼, 선택 강조, 오른쪽 설명 및 선택 버튼 구성을 참고했다. 원문 페이지는 접속에 실패했다.
- [기존 상점 화면 자료](https://siliconangle.com/2016/01/18/the-best-ways-to-spend-gold-or-money-in-hearthstone/): 검색 결과의 팩 전시, 수량 선택과 구매 버튼 분리를 참고했다. 2016년 상점이므로 현재 상점의 재현은 아니다.

## 반영

- 메인 중앙에 대전·투기장·선술집 난투·게임 모드, 아래에 카드팩·내 카드, 왼쪽 아래에 상점을 배치했다.
- 모드 선택은 원형 초상화 네 개와 선택 상태, 오른쪽 설명 및 확인 버튼으로 바꿨다.
- 상점은 카드·팩 전시와 수량·구매 영역으로 나눴다. 수량 선택만으로 재화를 소비하지 않는다.
- 퀘스트·업적은 두루마리 카드, 보상의 길은 레벨별 보상 경로로 분리했다. 보상 수령 후 현재 탭과 페이지를 유지한다.
- 기존 그림 자산을 재사용하고 실제 버튼과 진행 표시를 HTML로 구현했다. 원작 화면 이미지를 UI로 붙이지 않았다.

## 확인

- JavaScript 구문 검사 및 진행 시스템 테스트 6개 통과.
- 브라우저에서 난투 선택 → 선택 버튼 → 난투 덱 준비 화면 전환 확인.
- 5팩 선택 시 재화 유지, 구매 시 500골드 차감 및 5팩 증가, 잔액 부족 시 구매 비활성화 확인.
- XP 2000 테스트 상태에서 보상 페이지 이동, 1레벨 보상 수령, 중복 수령 비활성화 확인. 업적 수령 후 업적 탭 유지 확인.
- 1280×720에서 메인·모드·상점·퀘스트 화면을 직접 확인하고 캡처했다. 브라우저 오류 로그 없음.
- 575×900 에뮬레이션에서 미디어 쿼리 적용과 상점 컨테이너 크기를 확인했다. 실제 휴대폰 조작은 검사하지 않았다.
- 테스트는 localhost origin에서 수행했고 임시 구매·보상 데이터를 백업으로 복원했다. 사용자 게임 주소 127.0.0.1의 저장 데이터는 수정하지 않았다.

전투 연출, 최신 원작 클라이언트와의 픽셀 단위 대조, 실제 휴대폰 검증은 이번 범위에 포함하지 않았다.
