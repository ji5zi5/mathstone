2026-11-09. 기능 소개문을 늘리기보다 선택할 대상, 현재 상태, 다음 행동을 화면에서 구분하도록 수정했다.

## 변경

- 대전의 추천 덱 10개 나열을 없애고 저장한 내 덱만 표시한다. 견본은 새 덱 만들기에서 선택한다. 견본으로 생성한 덱은 독립된 내 덱으로 저장하고 편집 화면을 연다.
- 새 덱 진입점 세 곳(대전, 내 카드, 덱 관리)을 같은 선택 창으로 연결했다. 영웅과 빈 덱/견본을 고른다. 기존 저장 덱은 자동 변경하지 않는다.
- 대전 오른쪽에 일반/등급 선택, 영웅, 덱 이름, 마나 곡선, 시작 버튼을 배치했다. 영웅은 저장된 덱을 따른다. 능력 설명은 버튼을 눌러 읽는다.
- 덱이 없거나 미완성·보유 부족일 때 시작을 비활성화한다. 진행 중인 대전이 있으면 이어 하기를 제공한다.
- 투기장은 초상화 선택 및 확인 → 카드 세 장 비교 → 오른쪽 누적 덱, 아래 마나 곡선으로 구성했다. 카드 확대와 우클릭 상세 보기를 지원한다.
- 친구 기능처럼 보이던 방 코드 보관 기능은 ‘대전방 / 저장한 방’으로 표시한다.
- 긴 안내를 접을 수 있는 도움말로 옮겼다. 수학 능력을 별도 항목으로 설명하고, 덱의 전설 1장 제한을 명시했다.
- 업적 이름 아래에 승리·대전 완료·팩 개봉·주문 시전·제작 조건을 표시했다. 카드 능력 수치와 한 줄 대사는 이번에 변경하지 않았다.

## 검증

- `node --check src/app.js` 통과.
- `node --test tests/progression.test.mjs`: 6개 통과.
- 브라우저 assert: 초기 빈 덱 상태에서 시작 비활성화, 대전 화면 추천 덱 없음, 견본으로 30장 덱 저장, 지정 영웅 보존, 빈 덱 별도 생성 및 시작 비활성화.
- 저장 덱을 선택해 등급전 시작 후 저장 상태의 `mode=ranked`, `hero=leibniz`, `phase=mulligan` 확인.
- 투기장에서 아르키메데스 선택, 세 장 제시, 한 장 선택 후 1/30 및 마나 곡선 갱신, 새로고침 후 같은 제시 카드 유지, 우클릭 상세 보기 확인.
- 업적 조건 5개 표시, 도움말 접기/펼치기 구조를 확인했다. 브라우저 오류 로그 없음.
- localhost에서 만든 테스트 덱·대전·투기장 상태는 백업으로 복원했다. 127.0.0.1의 사용자 데이터는 수정하지 않았다.

플레이어 영웅은 기존 3명이다. 이번에는 영웅 능력 확장, 전투 전체 연출 개편, 실기기 모바일 검증을 하지 않았다.
