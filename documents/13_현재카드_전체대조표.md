# 현재 카드 전체 대조표

2026-11-09 · 현재 데이터 210장 · 수학자 본인 30장

**보존용 현황표다. 현재 효과를 추천하거나, 새 설계가 구현됐음을 뜻하지 않는다.** `src/cards.js`가 불러오는 전체 카드 데이터를 읽어 작성했다. 함수 카드는 게임의 `cardRules`를 이용해 실제 식이 보이는 문구로 기록했다. 이 표만으로 실행 결과와 문구의 일치를 검증한 것은 아니다.

[능력 설계안](12_우리게임의_수학능력_설계안.md)의 M01~M64와 연결했다. 연결된 번호는 재설계 후보이지 현재 효과 설명이 아니다. 같은 번호 아래 인물과 도구가 함께 있어도 두 카드의 최종 능력을 동일하게 만들겠다는 뜻은 아니다. 소환 토큰과 별도 영웅 능력은 아래 210장의 수에 포함하지 않는다.

- 능력 후보 번호에 연결된 카드: 85장
- 수학자 역할 방향만 제시한 카드: 7장
- 구체적인 새 능력을 아직 쓰지 않은 카드: 118장
